# Ventas

Vender con honestidad: entender por qué el cliente quiere esto, resolver dudas y acordar el siguiente paso.

## Guía base

`ventas-base`: cómo trabajar en esta área y qué no hacer nunca.

## Fichas

Frente al cliente:

- `entender-el-motivo`: Entender por qué el cliente quiere esto justo ahora, con sus palabras, y abrir la propuesta con ese motivo. Úsala al preparar o mejorar una propuesta o presupuesto antes de enviarla.
- `cuanto-cuesta`: Responder "¿cuánto cuesta?" con seguridad, después de entender el problema y sin decir que hay margen para bajar. Úsala cuando un cliente pregunta el precio antes de tener una propuesta.
- `es-caro`: Responder cuando un cliente dice que el precio es caro, que se pasa del presupuesto o pide descuento, sin bajar el precio. Úsala cuando llega esa objeción por chat, correo o llamada.
- `descuento-por-volumen`: Responder cuando el cliente pide un descuento a cambio de "mucho trabajo más adelante", sin regalar el precio por una promesa. Úsala cuando llega ese pedido por chat, correo o llamada.

Para el equipo:

- `fijar-el-precio`: Ayudar al equipo a elegir el precio de un servicio o producto con datos y no a ojo, y saber cuándo subirlo. Úsala con el dueño o el equipo, nunca frente a un cliente.
